# Models

This folder contains the financial models and source files
underlying the Treasury Hedging Workbook.

Contents:

- Treasury hedging workbook (.xlsm, macro-enabled)
- Macro-free copy (.xlsx)
- Rate scenario engine

A macro-free copy is provided for reviewers whose systems
block macro-enabled workbooks.

All models are built from publicly available information.
Figures are illustrative and prepared for portfolio purposes.
